# Blockchain Projects

This repository contains blockchain-related projects across different layer-1 ecosystems.
It is a progressive workspace that will expand over time as new examples, experiments, and integrations are added.

Most of the code here is written in **TypeScript** and **Rust**, since they cover the majority of practical blockchain use cases in this repo.

## Focus

- Layer-1 blockchain projects
- Progressive implementations that build up over time
- Practical examples and reusable scripts
- TypeScript for fast development workflows
- Rust for low-level and performance-sensitive work

## Current direction

The repository currently includes Solana-focused work, with more blockchain projects expected to be added as the workspace grows.
